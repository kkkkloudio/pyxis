# 🧭 Pyxis

> *Lo scrigno antico che punta. La bussola delle anime: tre lancette, niente GPS, niente nomi veri.*

Una web app minimale: **una sola bussola antica** con **tre lancette**.

- **Lancetta grande** → l'anima più vicina a te
- **Lancetta media** → la seconda anima più vicina
- **Lancetta piccola dorata** → il luogo sacro (POI) più vicino

Niente mappe, niente distanze in km, niente GPS. Solo la direzione relativa.

## 🚀 Demo

**https://kkkkloudio.github.io/pyxis**

## 📁 Struttura

```
pyxis/
├── index.html      # Tutta l'app (bussola + 3 lancette)
├── manifest.json   # PWA
├── assets/         # Texture pergamena, bussola, lancette
└── icons/          # Icone bussola (tutte le dimensioni)
```

## 🛠️ Sviluppo locale

```bash
python -m http.server 8000
# poi apri http://localhost:8000
```
